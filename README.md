# egosaint EPK

This is the public GitHub Pages edition of the egosaint electronic press kit. Publish from the root of the main branch. The site uses relative asset paths so it can run at /egosaintepk/.

Photos, artwork, and MP3s are included. The four show videos stream from the existing egosaintepk media service. Booking requests go to the existing private inbox through its HTTPS endpoint. Keep those services active for the galleries and contact form.
