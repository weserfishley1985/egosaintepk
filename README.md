# egosaint EPK

GitHub Pages publishes this site from the root of the main branch. Photos, artwork, audio, fonts, and all five full-length show videos use relative paths so they work at both the project address and a custom domain. The MP4 files in media/ are the web playback copies.

The booking form submits directly to the band's existing Formspree inbox. The site displays a receipt after Formspree accepts the request. If the form's Restrict to Domain option is enabled in Formspree, add the new domain there when switching addresses.
